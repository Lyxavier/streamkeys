Streamkeys MV3 Test Page

This page can be used to test the Streamkeys extension after MV3 migration.

Test Instructions:

  1. Load the extension in Chrome Developer Mode:
    • Open Chrome and go to chrome://extensions/
    • Enable "Developer mode" (top right toggle)
    • Click "Load unpacked"
    • Select the directory: D:\Documents\GitHub\streamkeys\streamkeys-master\build\mv3
    • The extension should load successfully now!
  2. Navigate to a supported music site (e.g., spotify.com, youtube.com)
  3. Test keyboard shortcuts:
    • MediaPlayPause - Play/Pause
    • MediaNextTrack - Next track
    • MediaPrevTrack - Previous track
    • Ctrl+Shift+2 - Mute
  4. Click the extension icon to test popup
  5. Check browser console and extension service worker for errors

Supported Sites:

  • Spotify
  • YouTube Music
  • SoundCloud
  • Pandora
  • Apple Music
  • Deezer

Troubleshooting:

  • Extension fails to load: Make sure you're loading the build/mv3 directory, not the root directory
  • "Required value 'name' is missing": Fixed - manifest now includes required name, version, and description
  • "web_accessible_resources parsing error": Fixed - updated to MV3 format with objects instead of strings
  • "require is not defined" popup error: Fixed - created new popup without browserify dependencies
  • "popup.css not found": Fixed - created standalone CSS file
  • Keyboard shortcuts not working: Check that the music site is supported and playing audio
  • Service worker errors: Check the Chrome extension's service worker console for errors
  • Popup not working: Ensure the popup HTML and JS files are properly loaded
